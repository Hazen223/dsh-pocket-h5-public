# Pocket · H5 预览工作台

Intel 独立应用的打包源码位于 `native/`。在有 Xcode Command Line Tools 的 Mac 上运行 `bash native/build-intel.sh`，会在临时目录生成 x86_64 的 `.app` 并打印路径；应用使用系统 Cocoa / WebKit，不依赖 Node.js。下面说明针对原始浏览器版。

双击 **启动预览.command** 即可启动并打开浏览器。需要本机 Node.js 18 或更新版本，无需安装任何依赖。也可以在此文件夹运行 `npm start`。

输入你的 H5 端口（例如 `5173`）、`localhost:3000/path` 或完整 HTTP / HTTPS 地址，然后点击「打开预览」。纯端口默认使用 `127.0.0.1`，避免部分代理环境对 localhost 的影响。你的 H5 项目需先自行启动。工具默认使用 `http://127.0.0.1:4177`，端口被其他应用占用时会向后寻找空闲端口；同一端口已有 Pocket 时直接打开。关闭浏览器不会停止服务，在启动窗口按 Control+C 停止。

支持 iOS 时间、电池电量、信号、Wi-Fi、灵动岛、手势条、横竖屏、画布缩放、安全区参考线、深浅文字、系统栏背景色、刷新、新窗口打开、最近地址与设置保存。可用 Command/Control + Enter 打开输入地址。

所有工具控件集中在左侧，右侧全高用于手机预览。新版 **100% 代表真机物理大小**：按 iPhone 17 的 460 PPI 和 @3x，将每个逻辑像素换算为 3/460 英寸；外框按 71.5 × 149.6 mm 绘制。50%、75%、125%、150% 都是相对于真机物理大小；「适应窗口」会利用右侧空间显示，并标明相对真机的比例。固定比例放不下时滚动查看，不会自动缩小。

工作台、内置示例与模拟机边框均为黑白灰。状态栏背景提供白、浅灰、黑三个选项。你自己的 H5 页面会保留原有颜色。

预览地址下方提供 SOCKS5 配置。**macOS 14 或以上的独立应用**中，展开 SOCKS5，启用代理，输入服务器、端口及可选账号密码，点击「应用代理配置」。它作用于 Pocket 内的网页请求，本机 `127.0.0.1`、`localhost` 和 `::1` 地址直连，不修改系统代理。关闭开关后再次应用，恢复系统网络设置。

代理端点保存在当前浏览器本地；账号密码只供当前应用运行会话使用，不写入设置文件。应用退出后代理不再启用，重新使用需要应用配置并按需重新输入认证信息。代理失败时不自动转为直连。界面「已应用」只表示系统接受了配置，实际连通性以 H5 页面加载为准。「新窗口打开 H5」使用外部浏览器自己的网络设置。浏览器版及 macOS 11–13 的应用内代理控件不可用。

原生应用通过系统报告的显示器毫米尺寸与逻辑分辨率估算换算系数，并在窗口更换显示器时更新。系统信息可能有误，所以保留标尺校准。浏览器无法可靠读取显示器物理尺寸，默认仅按 96 CSS px/英寸估算，首次需校准。

在左侧打开「校准实际尺寸」，用真实尺子测量线段两端间的长度，将毫米数填入并应用，即可使 100% 接近真机大小。标尺固定为 200 CSS px，校准通过实测毫米数计算每英寸 CSS px，不将 CSS 的 `mm` 单位或 `devicePixelRatio` 当作真实物理尺寸。校准按显示器保存；切换显示器、改变系统缩放或浏览器页面缩放后请检查。重置外观不会清除校准；「恢复系统估计」会清除当前显示器的手动校准。

尺寸校准只匹配物理大小，不能提高显示器实际像素密度，也不模拟真机的色彩、锐度或观看距离。

屏幕逻辑画布为 **402 × 874**，对应 iPhone 17 的 **1206 × 2622** 物理分辨率。缩放仅改变显示大小，不改变 H5 的 CSS 布局尺寸。规格来源：[Apple iPhone 17 技术规格](https://www.apple.com/iphone-17/specs/)。

- 默认预留顶部 62px、底部 34px，H5 内容区为 402 × 778。关闭系统栏后空间归还给 H5。
- 横屏逻辑画布为 874 × 402；默认预留左右各 62px 与底部 21px，内容区为 750 × 381；横屏隐藏时间和电池。
- 「全屏页面」将 H5 视口铺满逻辑屏幕，系统栏覆盖显示。系统栏尺寸为预览参考值，不能代替真机测量；参考线不会注入或改变 H5 的 `env(safe-area-inset-*)`。
- 设置、最近地址和最后预览地址保存在当前浏览器本地。点击「重置」恢复外观；浏览器清除此站点数据可清除全部记录。
- 可使用 `http://127.0.0.1:4177/?url=http%3A%2F%2Flocalhost%3A5173` 直接打开指定 H5。

这是基于 iframe 的本地外观和布局预览工具。它沿用桌面浏览器引擎、User-Agent、设备像素比及输入方式，不模拟 iOS Safari、软键盘或触摸事件。@3x 只展示设备规格。Safari 兼容性、设备能力与真实安全区请在真机上验证；H5 开发服务支持的热更新仍可正常使用。

页面空白时，先用新窗口按钮确认 H5 服务可访问。目标页面可能通过 `X-Frame-Options` 或 CSP `frame-ancestors` 禁止嵌入，可在你自己的开发服务里允许预览地址；工具不修改或绕过响应头。页面加载事件无法可靠判断跨域嵌入是否成功，界面不会将事件作为连接成功证明。浏览器可能还要求本地网络访问授权。

静态服务仅监听本机回环地址，不对局域网或公网发布，只提供本工具文件，不读取你的 H5 项目文件。独立应用的 SOCKS5 功能由系统 WebKit 执行。
