使用指南

让每个 H5，都有一部手机。

01

启动你的 H5，再输入地址

直接输入 5173、localhost:3000/path 或完整的 HTTP / HTTPS 地址。本工具不会替你启动 H5 项目。端口指向当前这台电脑。

02

按实际逻辑尺寸检查布局

竖屏为 402 × 874。默认预留顶部 62px、底部 34px，内容区为 402 × 778；横屏预留左右各 62px、底部 21px。这些系统栏和安全区是可视化参考值。

03

检查遮挡，或专注页面

「全屏页面」会让 H5 铺满屏幕，再覆盖状态栏与手势条。参考线只作提示，不会修改 H5 的 CSS，也不会把模拟值注入 env(safe-area-inset-*)。

如果页面空白

先点击「在新窗口打开」按钮，确认 H5 服务正在运行。目标页面的 X-Frame-Options 或 CSP frame-ancestors 可能禁止嵌入，需要在你自己的开发服务里允许此预览地址。HTTPS 页面也可能拦截 HTTP 嵌入。

嵌入页加载事件不代表页面一定成功显示。本工具不绕过网站限制；请只在自己的开发项目中调整设置。

画布沿用桌面浏览器的渲染引擎、User-Agent、设备像素比和输入方式。@3x 是规格说明；缩放不改变 iframe 的 CSS 尺寸。涉及 Safari、键盘、触摸、相机和真实安全区时，请在 iPhone 上验证。查看 Apple 屏幕规格 ↗
