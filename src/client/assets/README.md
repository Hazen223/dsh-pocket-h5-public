# 设备边框素材

`bezel.webp` + `bezel.json` 是面板里手机外框的素材与几何，**由用户提供的 iPhone 外框图**处理而来：

- 原图 1318×2718、透明背景；屏幕开口是一块 1206×2622 的浅色区域（正好是 402×874 @3x 的物理分辨率）；
- `tools/prepare-bezel.py` 把屏幕开口（含灵动岛）抠成透明、裁到外框 bbox、压成 WebP（约 62 KB）；
- `bezel-mask.webp` / `bezel-mask-landscape.webp`（各约 1.3 KiB）是**机身剪影**：把外框 alpha 的
  屏幕开口填满得到的实心轮廓。面板用它给 `.phone` 做 `mask-image`，把矩形页面裁到手机外轮廓里，
  避免外框圆角处露出页面白角；横屏用旋转 90° 的剪影。
- `bezel.json` 记录外框与屏幕开口的像素矩形，以及换算后的逻辑尺寸（÷3）：
  - portrait 外框 439.333×905.667 逻辑 px，屏幕开口在 (18.667, 16.0)；
  - landscape 是同一张图旋转 90°（左上角在左下）后的几何；
  - 圆角取图像开口半径 270 px ÷ 3 = 90 逻辑 px。

面板只把边框当作 `.phone` 的装饰背景（`::before`），`.screen` 按上面的几何定位在屏幕开口上；
因此 H5 的逻辑尺寸仍是 402×874，手感上 100% 仍按 iPhone 17 的 460 PPI/@3x 换算。

如果换边框：把新图传给 `python3 tools/prepare-bezel.py <frame.png>` 重新生成两个文件即可
（脚本会校验屏幕开口必须是 1206×2622）。
